# Asset sources

Every sourced asset in Menagerie comes from one of the jars below. All seven were
**license-verified individually before anything was imported**: each declares
`license="Unlicense"` in its loader metadata *and* ships the complete Unlicense
dedication text in the jar root (checked by reading the file, not the filename — a file
called `LICENSE` can contain anything). The Unlicense places the work in the public
domain, so asset and code reuse is cleared outright, commercial or not, with no
attribution required. We credit anyway; see `CREDITS.md`.

Jars live in `~/Desktop/Animal mods open source/` and are unpacked to `work/sources/`
(gitignored — the sources are not redistributed from this repo).

| Source | Taken | Where it lives |

Derived work: `textures/entity/gorilla/albino.png` is generated by
`tools/gen-textures.js` from the sourced `default.png` — every UV pixel stays in place,
the coat is remapped to cream and the bare-skin rects are tinted, so it is provably the
same gorilla in white rather than new art.

The remaining five jars are unpacked, inventoried and cleared, but nothing has been
imported from them yet. See `RESEARCH.md` for the port notes and the backlog.

## One discrepancy worth recording

`untamedanimalz` is Untamed Wilds (modid `untamedwilds`, RayTrace082). The **public
GitHub repository for Untamed Wilds is GPL-3.0** — this project verified that directly
during Phase 1 research, and it is still recorded in `RESEARCH.md`. This jar is a
different artifact: it is self-consistently Unlicense (metadata *and* full dedication
text), which is what a deliberate public-domain re-release looks like. Both facts are
recorded here rather than quietly resolved, because the two artifacts genuinely
disagree and anyone auditing this later deserves to see that.
